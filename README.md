
# 🌐 Movement Network Foundation: Official Project Profile

## 🚀 Core Mission & Vision

Movement is a **Modular Framework** designed to build and deploy Move-based infrastructures, applications, and blockchains in any distributed environment. It helps you leverage the power of the Move Programming Language for non-Move protocols without having to write a single line of Move code.

### 💰 Funding & Scale

  * **Total Funding:** $141.4M (including $100M Series B led by Binance Labs).
  * **Mainnet Status:** Beta is Live with $250M TVL.
  * **Flagship Release:** M1 (Solidity-compatible, Vertically Composable & Horizontally Scalable L1).
